# دحروج

كرة جيلي صغيرة بعيون، تنبعج وتترجرج وتقفز وترتد، وتفرح معك إذا سجّلت وتضحك عليك إذا خربت.

**العب الآن:** [3wasfnjd.github.io/Dahrooj](https://3wasfnjd.github.io/Dahrooj/)

## الأنماط
- **حر**: قفز وسحب ورمي للكرة.
- **مرمى**: سدّد على حارس يصد.
- **سلة**: رمية بقوس عالي.
- **بادل**: رالي مع الجدار الزجاجي.
- **شباك**: مربع يصغر كل ما دخلت فيه.
- **علب**: طيّح هرم العلب.
- **Duel**: مواجهة أونلاين ضد لاعب آخر، أو ضد خصم آلي إذا ما فيه أحد.

## الستايلات
Jelly · Fabric · Clay · Fur · Bubble
