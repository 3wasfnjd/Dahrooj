# دحروج

كرة جيلي صغيرة بعيون، تنبعج وتترجرج وتقفز وترتد، وتفرح معك إذا سجّلت وتضحك عليك إذا خربت.

## صفحة البداية

تُستخدم صورة البوستر المرفقة كاملةً خلفيةً للبداية دون قص أو تشويه، مع زر **بدء اللعبة** واسم **Aboden Games** فقط فوقها، دون عنوان أو عبارة إرشادية إضافية. تتساقط الكور بالاستايلات الخمسة الأصلية وتتكدّس بالتصادم حتى تصل لأعلى الشاشة؛ بعدها يظهر زر البدء. يمكن سحب أي كرة ورميها باللمس أو الماوس، حتى بعد ظهور الزر. الدخول للعبة بالزر فقط.

في إعداد تقليل الحركة تظهر الكور متراكمة مباشرة وتبقى قابلة للسحب. تتوقف محاكاة البداية وتُزال عند الدخول، وتبدأ الموسيقى الموجودة مع أول تفاعل وفق اختيار الكتم المحفوظ. لا تُضاف نقاط أو تحديات من كور البداية.

لكل كرة تعبير مستقل من ستة تعابير اللعبة الأصلية، مع رمش متفرق ودهشة عند سحبها. توزيع كل دفعة من ٢٠ كرة: ٩ قماش، ٤ جيلي، ٣ فرو، ٣ فقاعات وكرة صلصال واحدة، بترتيب عشوائي.

الضغط المطوّل لمدة نحو ٠٫٦٥ ثانية يفقع كرة البداية، مع مؤشر دائري وصوت فرقعة خفيف. تحريك الإصبع يبدأ السحب ويلغي الفرقعة لهذه اللمسة. بعد ظهور زر البدء يبقى متاحًا حتى لو فقعت الكور؛ وقبل امتلاء الصفحة يستمر تساقط الكور لتعويضها.

فحص الصفحة: `npm ci --prefix tools` ثم `npx --prefix tools playwright install --with-deps chromium webkit` ثم `node tools/test-start-screen.mjs`. فحص الفرقعة واللمس وإلغاء الضغط: `node tools/test-start-pop.mjs`. النتائج والصور في `test-results/`. فحوص `test-startup.mjs` و`test-music.mjs` القديمة تقارن تعديلات تاريخية بنسخ سابقة حرفيًا؛ ليست فحص صفحة البداية الجديدة.

## الأنماط
- **حر**: اضغط مطوّلًا وأفلت لتقفز، أو اقرص الكرة من أي نقطة ومطّها وارمها.
- **مرمى**: اسحب لفوق وسدّد، وفيه حارس برتقالي يصد.
- **سلة**: نفس السحبة بقوس أعلى.
- **بادل**: رالي مع الجدار الزجاجي، اضرب لما تتلوّن الدائرة.
- **شباك (Window)**: مربع صغير، كل ما دخلت فيه ينتقل ويصغر.
- **علب**: طيّح هرم العلب الحديدية.
- **Duel**: منافسة بين لاعبين مع خصم آلي عند عدم توفر لاعب آخر. أول اثنين يدخلان النمط يتقابلان تلقائيًا في مباراة مستقلة، دون إنشاء غرفة أو رمز. يبدأ الزائر المنفرد اللعب ضد شخصية دحروج بستايل مختلف دائمًا عن ستايل اللاعب؛ وعند توفر منافس حقيقي تنتهي الرمية الجارية ثم تبدأ مواجهة جديدة بنقاط وحياة مستقلة. خروج المنافس يعيد اللعب مع خصم آلي ويستمر البحث تلقائيًا.

الرمي الأساسي بالتناوب وبنفس فيزياء دحروج. يستطيع اللاعبان تحريك شخصيتهما بالسحب الأفقي وهي على الأرض؛ السحب للأعلى يرمي دحروج وقت دوره. يمكن التحريك بإصبع والرمي بإصبع آخر في الوقت نفسه؛ لكل لمسة تحكم مستقل، وإفلات إصبع الحركة لا يطلق الرمية. أثناء دور المنافس، لمسة في مكانه ترمي كورة صغيرة بلا عيون وبنفس خامة وستايل صاحبها لحظة الرمي نحو موضع اللمسة، دون تتبع بعد الإطلاق ودون أزرار أو أيقونات للمقذوفات. اللمسة الملغاة لا ترمي. يمكن تكرار اللمس لرمي كور متتابعة قبل وصول الكورة السابقة، مع استمرار التحريك بالإصبع الآخر.

تظهر أسفل النتيجة أيقونة سوداء صغيرة: علامة تصويب لدورك، وساعة رملية أثناء دور الخصم، وبجانبها أيقونة روبوت باهتة إذا كان الخصم آليًا. تحتها شريطان بلا نص (حياتك يسارًا وحياة المنافس يمينًا): الحياة 100، ضربة دحروج 40، والكورة الصغيرة 20 عند الاصطدام الفعلي، بحد أقصى ثلاث إصابات (60) في كل دور حتى لا تُفقع حياة كاملة بالكور الصغيرة وحدها. تبقى الحياة بين الأدوار؛ الصفر يفقع اللاعب بالجزيئات والصوت الموجودين، دون حلقة بيضاء، وتُحسب نقطة للخصم ثم تبدأ جولة بحياة كاملة. الأنماط الستة الأخرى تبقى محلية.

### تشغيل Duel

رابط اللعبة الأساسي يبقى [https://3wasfnjd.github.io/Dahrooj/](https://3wasfnjd.github.io/Dahrooj/). عند اختيار Duel يتصل هذا الموقع بخادم اللعب `dahrooj-duel.glory-noon.workers.dev` في الخلفية، دون تحويل اللاعب إلى رابط آخر. يشارك زوار الرابطين صف المطابقة نفسه. الاستضافة الثابتة تعرض اللعبة، وWorker يشغّل الأونلاين والخصم الآلي.

- محليًا: `npm ci` ثم `npm run dev`، وافتح العنوان المطبوع في متصفحين منفصلين واختر Duel. للتجربة بين أجهزة الشبكة المحلية: `HOST=0.0.0.0 npm run dev` وافتح عنوان جهاز الخادم من الجهازين.
- النشر الحالي من `main`: GitHub Pages ينشر واجهة اللعبة على رابطها الأساسي، وCloudflare Builds ينشر Worker من المستودع نفسه باستخدام `npm run build` ثم `npx wrangler deploy`.
- للنشر اليدوي للخادم: من `main` شغّل `npx wrangler login` ثم `npm run deploy`. إعداد `wrangler.jsonc` يستخدم Worker الحالي `dahrooj-duel`.
- سير العمل `Duel online` يفحص `main` وفرع الميزة. نشر `main` تديره Cloudflare Builds؛ خطوة النشر الاختيارية ببيانات GitHub Secrets تبقى خاصة بفرع الميزة.

الخادم يحدد حركة الشخصيتين والمشتتات والإصابات والحياة والنقاط؛ لا يقبل نقاطًا أو مواضع يرسلها اللاعب. صف الانتظار يرتّب اللاعبين بحسب وصول طلب الدخول. ربط الرسائل بالمباراة يتم من الاتصال نفسه. عند انقطاع الاتصال يحاول المتصفح الاتصال تلقائيًا. الخصم الآلي يعمل على نفس الخادم وبنفس قواعد الحركة والإصابة؛ لا يعمل نمط Duel دون اتصال بالخادم. حالات المباريات الساكنة تُحفظ مع اتصالات Durable Object أثناء السبات.

الفحص: `npm test` لاختبارات الفيزياء والمطابقة والعزل والانقطاع والرسائل غير الصالحة واتصالات WebSocket الفعلية. لفحص المتصفحات: `npm ci --prefix tools` ثم `npx --prefix tools playwright install chromium` ثم `npm run test:browser`. يفحص أربعة لاعبين ولاعبًا خامسًا يلعب ضد خصم آلي، الرمي من الطرفين، الستايلات الخمسة والفرقعة بلا حلقة، إعادة الاتصال، وأحجام الشاشة والأنماط الأصلية. التقرير والصور في `test-results/`.

## الستايلات
تختارها من أعلى اليسار:
- **Jelly**: لامع ومعه لزقة جروح.
- **Fabric**: قماش لبّاد عنابي بخياطة وغرزة X.
- **Clay**: صلصال بني يحتفظ بأثر الضربة، وعليه بصمة إبهام.
- **Fur**: فرو أبيض ببقع بني، شعره يتحرك مع الحركة، وعلى راسه فيونكة.
- **Bubble**: فقاعة صابون تنفقع مع الضربة القوية وترجع تتكوّن.

## التشغيل
انشر محتويات المستودع كاملة أو شغّلها بخادم ملفات ثابت. `index.html` يستخدم Three.js r128 والخطوط من مجلد `vendor/` المحلي، ولا يحتاج مواقع طرف ثالث لبدء اللعب المحلي. نمط Duel وحده يحتاج الاتصال بالخادم الموضح أعلاه. لا تنقل ملف HTML وحده. مثال للتجربة: `python3 -m http.server 8000`.

Firebase اختياري لعدّاد الزيارات فقط؛ فشل الاتصال لا يوقف اللعبة. لا يوجد Service Worker ولا ضمان لتشغيل الموقع دون إنترنت بعد إغلاقه. ملف `.nojekyll` يبقي ملفات vendor متاحة على GitHub Pages.

تراخيص المكتبة والخطوط ومصادرها في [vendor/README.md](vendor/README.md). نتائج فحص الجوال وقياس حجم البدء في [docs/startup-report.md](docs/startup-report.md).

قصاصات الاحتفال منقولة من مشروع [Motri](https://github.com/3wasfnjd/Motri).
