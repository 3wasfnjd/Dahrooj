# دحروج

كرة جيلي صغيرة بعيون، تنبعج وتترجرج وتقفز وترتد، وتفرح معك إذا سجّلت وتضحك عليك إذا خربت.

## صفحة البداية

تُستخدم صورة البوستر المرفقة كاملةً خلفيةً للبداية دون قص أو تشويه، مع زر **بدء اللعبة** واسم **Aboden Games** فقط فوقها، دون عنوان أو عبارة إرشادية إضافية. تتساقط الكور بالاستايلات الخمسة الأصلية وتتكدّس بالتصادم حتى تصل لأعلى الشاشة؛ بعدها يظهر زر البدء. يمكن سحب أي كرة ورميها باللمس أو الماوس، حتى بعد ظهور الزر. الدخول للعبة بالزر فقط.

في إعداد تقليل الحركة تظهر الكور متراكمة مباشرة وتبقى قابلة للسحب. تتوقف محاكاة البداية وتُزال عند الدخول، وتبدأ الموسيقى الموجودة مع أول تفاعل وفق اختيار الكتم المحفوظ. لا تُضاف نقاط أو تحديات من كور البداية.

لكل كرة تعبير مستقل من ستة تعابير اللعبة الأصلية، مع رمش متفرق ودهشة عند سحبها. توزيع كل دفعة من ٢٠ كرة: ٩ قماش، ٤ جيلي، ٣ فرو، ٣ فقاعات وكرة صلصال واحدة، بترتيب عشوائي.

الضغط المطوّل لمدة نحو ٠٫٦٥ ثانية يفقع كرة البداية، مع مؤشر دائري وصوت فرقعة خفيف. تحريك الإصبع يبدأ السحب ويلغي الفرقعة لهذه اللمسة. بعد ظهور زر البدء يبقى متاحًا حتى لو فقعت الكور؛ وقبل امتلاء الصفحة يستمر تساقط الكور لتعويضها.

فحص الصفحة: `npm ci --prefix tools` ثم `npx --prefix tools playwright install --with-deps chromium webkit` ثم `node tools/test-start-screen.mjs`. فحص الفرقعة واللمس وإلغاء الضغط: `node tools/test-start-pop.mjs`. النتائج والصور في `test-results/`. فحوص `test-startup.mjs` و`test-music.mjs` القديمة تقارن تعديلات تاريخية بنسخ سابقة حرفيًا؛ ليست فحص صفحة البداية الجديدة.

## الأنماط
- **حر**: اضغط مطوّلًا وأفلت لتقفز، أو اقرص الكرة من أي نقطة ومطّها وارمها.
- **مرمى**: اسحب لفوق وسدّد، وفيه حارس برتقالي يصد.
- **سلة**: نفس السحبة بقوس أعلى.
- **بادل**: رالي مع الجدار الزجاجي، اضرب لما تتلوّن الدائرة.
- **شباك (Window)**: مربع صغير، كل ما دخلت فيه ينتقل ويصغر.
- **علب**: طيّح هرم العلب الحديدية.
- **Duel**: منافسة أونلاين بين لاعبين. اختيار النمط يدخل اللاعب في الانتظار تلقائيًا؛ أول اثنين يتقابلان في مباراة مستقلة، ثم الاثنان التاليان في مباراة أخرى، دون إنشاء غرفة أو إدخال رمز. يلعب الاثنان بالتناوب بنفس رمية العلب وفيزياء دحروج: الأول يرمي والثاني ينتظر، ثم ينتقل الدور بعد الإصابة أو انتهاء الرمية. تظهر أسفل النتيجة أيقونة سوداء صغيرة: علامة تصويب لدورك، وساعة رملية أثناء دور الخصم. الشخصية بنفس الحجم الفعلي والمنظور؛ شريط صغير بلا نص فوق كل شخصية يعرض الحياة: 100 نقطة، ضربة دحروج 40، والمشتت 20 عند الاصطدام الفعلي. تبقى الحياة بين الأدوار؛ عند وصولها للصفر ينفقع اللاعب بالجزيئات والصوت الموجودين دون حلقة بيضاء، وتُحسب نقطة للخصم ثم تبدأ جولة بحياة كاملة. العداد يعرض نقاطك يسارًا ونقاط الخصم يمينًا. يعود اللاعبان بعد الإصابة، وعند خروج أحدهما يرجع الآخر للانتظار تلقائيًا. لكل لاعب ستايله الأصلي المختار. الأنماط الستة الأخرى تبقى محلية.

### تشغيل Duel

يحتاج هذا النمط خادم WebSocket؛ استضافة الملفات الثابتة وحدها (مثل GitHub Pages أو رابط raw.githack) لا تشغّل المطابقة.

- محليًا: `npm ci` ثم `npm run dev`، وافتح العنوان المطبوع في متصفحين منفصلين واختر Duel. للتجربة بين أجهزة الشبكة المحلية: `HOST=0.0.0.0 npm run dev` وافتح عنوان جهاز الخادم من الجهازين.
- النشر: من الفرع `feature/cans-ai-opponent` شغّل `npx wrangler login` ثم `npm run deploy`. ينشر إعداد `wrangler.jsonc` اللعبة والخادم معًا في Worker مستقل اسمه `dahrooj-duel`، ويطبع الرابط. افتح هذا الرابط على الأجهزة المشاركة.
- تجربة مؤقتة دون ربط حساب: `npx wrangler deploy --temporary`. يُطبع رابط اللعب ورابط خاص لاستلام النشر في Cloudflare؛ أكمل الاستلام خلال المهلة المطبوعة (٦٠ دقيقة)، وإلا يُحذف النشر المؤقت. لا تضع رابط الاستلام أو بياناته في المستودع.
- للنشر المستمر، يمكن ربط Worker بهذا المستودع والفرع في Cloudflare Builds، أو إعداد سرَّي GitHub Actions: `CLOUDFLARE_API_TOKEN` و`CLOUDFLARE_ACCOUNT_ID`. سير العمل `Duel online` ينشر عند توفرهما بعد نجاح الفحوص. لا يتصل بالفرع الرئيسي.

الخادم يحدد حركة الشخصيتين والمشتتات والإصابات والحياة والنقاط؛ لا يقبل نقاطًا أو مواضع يرسلها اللاعب. صف الانتظار يرتّب اللاعبين بحسب وصول طلب الدخول. ربط الرسائل بالمباراة يتم من الاتصال نفسه. عند انقطاع الاتصال يحاول المتصفح الاتصال تلقائيًا؛ لا يستبدل اللاعب بذكاء اصطناعي. حالات المباريات الساكنة تُحفظ مع اتصالات Durable Object أثناء السبات.

الفحص: `npm test` لاختبارات الفيزياء والمطابقة والعزل والانقطاع والرسائل غير الصالحة واتصالات WebSocket الفعلية. لفحص المتصفحات: `npm ci --prefix tools` ثم `npx --prefix tools playwright install chromium` ثم `npm run test:browser`. يفحص أربعة لاعبين ولاعبًا خامسًا ينتظر، الرمي من الطرفين، الستايلات الخمسة والفرقعة بلا حلقة، إعادة الاتصال، وأحجام الشاشة والأنماط الأصلية. التقرير والصور في `test-results/`.

## الستايلات
تختارها من أعلى اليسار:
- **Jelly**: لامع ومعه لزقة جروح.
- **Fabric**: قماش لبّاد عنابي بخياطة وغرزة X.
- **Clay**: صلصال بني يحتفظ بأثر الضربة، وعليه بصمة إبهام.
- **Fur**: فرو أبيض ببقع بني، شعره يتحرك مع الحركة، وعلى راسه فيونكة.
- **Bubble**: فقاعة صابون تنفقع مع الضربة القوية وترجع تتكوّن.

## التشغيل
انشر محتويات المستودع كاملة أو شغّلها بخادم ملفات ثابت. `index.html` يستخدم Three.js r128 والخطوط من مجلد `vendor/` المحلي، ولا يحتاج مواقع طرف ثالث لبدء اللعب المحلي. نمط Duel وحده يحتاج الاتصال بالخادم الموضح أعلاه. لا تنقل ملف HTML وحده. مثال للتجربة: `python3 -m http.server 8000`.

Firebase اختياري لعدّاد الزيارات فقط؛ فشل الاتصال لا يوقف اللعبة. لا يوجد Service Worker ولا ضمان لتشغيل الموقع دون إنترنت بعد إغلاقه. ملف `.nojekyll` يبقي ملفات vendor متاحة على GitHub Pages.

تراخيص المكتبة والخطوط ومصادرها في [vendor/README.md](vendor/README.md). نتائج فحص الجوال وقياس حجم البدء في [docs/startup-report.md](docs/startup-report.md).

قصاصات الاحتفال منقولة من مشروع [Motri](https://github.com/3wasfnjd/Motri).
