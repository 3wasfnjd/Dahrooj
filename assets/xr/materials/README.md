# Surface detail for Dahrooj's styles

From [@pmndrs/assets](https://www.npmjs.com/package/@pmndrs/assets) 1.7.0 (normal maps resized to 512×512 WebP from [emmelleppi/normal-maps](https://github.com/emmelleppi/normal-maps)), **CC0 1.0** (see `LICENSE`).

- `knit-normal.webp`: normals `0019`, knitted wool, used on the fabric style.
- `clay-normal.webp`: normals `0000`, finger presses, used on the clay style.

`../dahrooj3d.js` loads them over its own drawn surfaces, which stand in until they arrive.
